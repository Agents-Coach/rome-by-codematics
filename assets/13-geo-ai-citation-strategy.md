## WHAT IS GEO?

GEO (Generative Engine Optimization) = optimizing content to be cited as a source by AI search engines (Perplexity, Claude, ChatGPT, Gemini, Copilot).

Unlike traditional SEO where you optimize for Google, GEO optimizes for AI chatbots that answer questions directly.

**Why it matters for Rome:**
- Rome's target audience (coaches, consultants) increasingly uses Perplexity and ChatGPT to research solutions
- Getting cited as a source by AI = free brand awareness + authority + traffic
- GEO is much less competitive than Google SEO right now
- Rome's "AI sales agent on WhatsApp" positioning is novel — first mover advantage is available

---

## HOW AI CITATIONS WORK

AI search engines cite sources using:
1. **Training data** — content from 2021–2024
2. **Web search** — real-time search at query time
3. **Structured data** — FAQ schema, HowTo schema, Q&A pages
4. **Entity signals** — Wikipedia, Wikidata, brand mentions across the web
5. **Citation networks** — pages that other trusted sites link to

**Rome's citation opportunity:** "WhatsApp AI sales agent" is a new category. There is no dominant source. Whoever creates the most authoritative content gets cited.

## GEO OPTIMIZATION TACTICS

### Tactic 1: Q&A Content Architecture
Create dedicated Q&A pages that directly answer the target questions above.

**Page structure for each target question:**
```
/qa/whatsapp-ai-sales-agent-for-coaches
/qa/automate-whatsapp-coaching-business
/qa/whatsapp-automation-vs-ai-chatbots
/qa/how-ai-sales-agents-work-whatsapp
```

**Each Q&A page must include:**
- Direct answer in the first 2 sentences (AI reads this)
- Followed by detailed explanation
- Bullet points for scannability
- FAQ schema (structured data)
- Internal links to other Rome pages
- External links to authoritative sources (WhatsApp Business, Anthropic, etc.)

### Tactic 2: Entity Building
Build Rome's presence on authoritative knowledge bases.

**Wikipedia page for Rome by Codematics:**
Create a Wikipedia article (or get notable enough to have one created):
- Neutral, factual tone
- Company name, founding, product description
- Key differentiators
- Press mentions

**Wikidata entry:**
Create Wikidata entry with Rome's entity data:
- Name, type (software product)
- Official website
- Developer (Codematics)
- Programming language (TypeScript, Node.js)
- License
- Related entities

**Google Knowledge Panel optimization:**
- Claim and verify Rome's Knowledge Panel when it appears
- Ensure Wikipedia exists
- Get cited on major tech/news sites

### Tactic 4: Citation Network Building
Get Rome mentioned on authoritative sites:

**Target citations:**
- [ ] TechCrunch / YourStory / Business Insider India (press)
- [ ] AI news sites (VentureBeat, The Verge, MIT Tech Review)
- [ ] Coaching/business blogs that link to tools
- [ ] GitHub (Rome Bridge open-source mention)
- [ ] LinkedIn articles from Rome users
- [ ] Reddit discussions (natural, non-spammy)

**How to get cited:**
1. Publish original research (e.g., "State of WhatsApp Automation in India 2026")
2. Create a free tool or template (Rome ROI calculator as a standalone page)
3. Guest post on coaching business blogs
4. Submit Rome to product directories (Product Hunt, AlternativeTo, G2)

### Tactic 5: Perplexity Publisher
Get Rome verified as a Perplexity Publisher:
- Go to perplexity.com/publisher
- Submit Rome's website
- This allows Rome to claim citations and get notified when cited

**Citation notification:** When Perplexity cites Rome, get notified. Engage with the thread, build relationship.
