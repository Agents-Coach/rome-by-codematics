## LAUNCH PRE-MORTEM (Risks)

### Risk 1: WhatsApp API issues on launch day
**Likelihood:** High
**Mitigation:** Test the full flow with 3 beta users 48 hours before launch

### Risk 2: Stripe payment failures
**Likelihood:** Medium
**Mitigation:** Use Stripe test mode until confirmed working, then switch to live

### Risk 3: Evolution API rate limits
**Likelihood:** Low
**Mitigation:** Monitor API usage, have escalation path to Meta Cloud API

### Risk 4: Low waitlist conversion
**Likelihood:** Medium
**Mitigation:** A/B test waitlist landing page; warm up list with value emails before launch

### Risk 5: Competitor awareness
**Likelihood:** Low
**Mitigation:** Launch fast, establish first-mover advantage in "AI WhatsApp agent" category

## WHAT TO DO IF LAUNCH FLATLINES

**If Day 3 signup rate < 5:**
- A/B test landing page headline immediately
- Check which traffic source converts (Google vs LinkedIn vs direct)
- Double down on what's working

**If WhatsApp connect rate stays < 30%:**
- Show QR code immediately after signup (don't wait for dashboard)
- Send WhatsApp message to user with QR code link

**If trial → paid conversion < 10%:**
- Send personalized follow-up email to every trial user
- Offer a live demo call
- Check for friction in payment flow
